# Homework Description
The goal is to predict whether two nodes in 'test.csv' are in the same community. Please submit the results in the designated format.

# Data Description
## Files
- train.csv - the training set
- test.csv - the test set
- sample_submission.csv - a sample submission file in the correct format

## Columns Description
1. train.csv
    - `Node1` `Node2` - represent the edge between two nodes
2. test.csv
    - `Id` - represent the index of your prediction
    - `Node1` `Node2` - represent the pairs to determine whether they are in the same community
3. sample_submission.csv
    - `Id` - represent the index of your prediction
    - `Category` - represent the answer of your prediction
